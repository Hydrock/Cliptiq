# Cliptiq

Компактный менеджер буфера обмена на C++17 для Windows, macOS и Linux.
Общее SQLite-ядро и нативный интерфейс: Win32, AppKit, GTK3.

Реализованы история, несколько форматов буфера, меню/tray, горячие клавиши,
вставка, сниппеты и редактор, настройки, privacy-фильтры, превью, наблюдение
за папкой скриншотов, автозапуск, локализация и локальная диагностика.
OCR/FTS — отдельные опциональные сборки; пользовательского поиска пока нет.

Совместимость с Clipy (XML и миграция) удалена по решению пользователя:
[границы изменения](docs/support/clipy-compatibility-retired.md).
Исследование Clipy и отчёты T11/T14 сохранены как исторические материалы.

Пользовательский production-выпуск заблокирован ручной приёмкой и подписью.
Ограничения Wayland зависят от окружения; автоматические тесты не заменяют
проверки реальных desktop-приложений.
