# Cliptiq

Планируемый компактный менеджер буфера обмена для macOS, Windows и Linux на основе поведения [Clipy](https://github.com/Clipy/Clipy).

Реализовано C++17 ядро постоянной истории и privacy/capability gate (T02–T03). Нативные оболочки и готовые пользовательские сборки ещё не созданы.
