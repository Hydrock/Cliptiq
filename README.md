# Cliptiq

Планируемый компактный менеджер буфера обмена для macOS, Windows и Linux на основе поведения [Clipy](https://github.com/Clipy/Clipy).

Реализовано начальное C++17 ядро постоянной истории (T02). Нативные оболочки и готовые пользовательские сборки ещё не созданы.
