# T17: условия выпуска

CI создаёт кандидаты, выпуск пользователям заблокирован. Машинный источник — `release-checklist.json`; проверка `python tools/verify-release.py --checklist docs/support/release-checklist.json` обязана завершаться ошибкой, пока условия OPEN. `--expect-blocked` проверяет именно сохранение блокировки и не подтверждает готовность выпуска.

Ручная приёмка T04–T16 остаётся OPEN по указанию пользователя. Нужны настоящие desktop-сессии: ввод/вставка с модификаторами и возвратом фокуса, конфликт горячих клавиш, меню/редактор/preview/accessibility, отмена разрешений, pause/resume и restart desktop. Для OCR — реальные language packs и положительная проверка Windows package identity; для Wayland — конкретный compositor с data-control/portal, а не обещание универсальной поддержки.

На чистых потребительских системах требуется проверить установку/удаление, offline-поведение, системные библиотеки и размер их дополнительной установки. Доступных чистых ВМ нет: CI/извлечение DEB и запуск `--version` этого не заменяют. Неизвестные размеры системного delta/offline closure остаются `null`.

Перед публикацией нужны выбранная лицензия проекта, production publisher identity, подпись Windows и проверка pinned SHA256 сертификата, macOS Developer ID/notarization/stapling; для Linux — аутентифицированный маршрут репозитория пакетов. Текущие MSIX unsigned, macOS ad-hoc; это не доверенные устанавливаемые production-пакеты. MakeAppx выполняет семантическую проверку без `/nv`.

Native CI: macOS 15 ARM64 и Intel, Windows 2025 x64, Ubuntu 24.04 x64. Windows/Linux ARM64 и universal macOS не объявлены поддерживаемыми измеренными сборками. Перед таким расширением нужны native smoke и отдельные бюджеты. Версия macOS deployment target 13 не является доказательством desktop-приёмки на macOS13.

Base и OCR выпускаются раздельно. Модели Tesseract EN/RU находятся только в optional OCR. Старые опциональные Realm importer и Sparkle SDK сохраняют отдельные T14/T15 build/test/size jobs и не добавляются в Base. Полностью объединённый набор всех опций отдельно не измерен и не заявлен.

Внешние Actions закреплены commit SHA, исходники зависимостей — существующими hash locks. Образы hosted runners и системные SDK/компиляторы обновляемые: точные используемые пути/версия CMake/платформа записаны в манифест кандидата; bit-for-bit reproducibility и полностью герметичный toolchain не заявлены. Перед production следует закрепить образ/SDK и воспроизвести сборку.

Контроль размеров: кандидат Base ≤10MiB app /5MiB ZIP; OCR ≤16MiB /8MiB; одновременно не более +10% относительно отдельного T16 baseline с явной allowance12000B на лицензии/manifest. Это инженерные ограничения, не согласованный окончательный продуктовый бюджет. Пакеты DEB/RPM/MSIX/tar также измеряются отдельно, ZIP служит общим сравнимым сжатым показателем. Системные библиотеки не прибавляются как нулевые.
