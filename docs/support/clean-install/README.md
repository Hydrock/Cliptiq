# T01: установка и зависимости

Дата: 23 октября 2026. Windows/macOS: свежий профиль и распаковка portable ZIP на GitHub-hosted runner, **не чистая ОС**. Пользователь подтвердил отсутствие отдельных чистых ВМ и согласовал явную фиксацию этого ограничения. `clean_vm_verified=false` сохранено в JSON; предварительно установленные средства runner могут влиять на результат.

Linux: одноразовый минимальный Ubuntu 24.04 контейнер с точным image digest, отрицательная проверка до установки библиотек (exit 127), скачивание runtime и GUI harness раздельно, отключение сети контейнера, установка из локальных DEB, fixture/XML parity и реальный оконный lifecycle. В GTK3 дополнительно проверены установка, запуск и удаление нашего DEB. Это чистый userland, не desktop VM.

| Вариант | Download зависимостей, bytes | Прирост runtime, bytes | C++ app + runtime, bytes |
|---|---:|---:|---:|
| GTK3 | 37 269 652 | 141 422 111 | 142 150 223 |
| GTK4 | 37 884 896 | 147 262 609 | 147 990 721 |
| GTK3 + OCR EN/RU | 48 862 382 | 171 250 572 | 171 982 780 |

Прирост — logical/apparent filesystem bytes, не allocated disk usage. Xvfb и test harness устанавливаются после замера и исключены из runtime delta. В минимальном image уже есть базовые OS библиотеки; их размер не включён повторно в прирост. Это не размер полностью автономного установщика. На desktop часть библиотек уже присутствует.

Исходные package inventories, SHA256 каждого runtime DEB и результаты проверок находятся в linux-*; profiles содержит отдельные CI отчёты Windows/macOS и локальную Windows-пробу. В каждом запуске используется новый каталог, чтобы старые версии DEB не увеличивали сумму. Повторные чистые запуски воспроизвели цифры.
