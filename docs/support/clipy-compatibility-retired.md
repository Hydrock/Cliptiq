# Совместимость с Clipy удалена из объёма продукта

12 ноября 2026 пользователь явно отказался от обратной совместимости с Clipy.
S05 (импорт XML), S06 (экспорт XML) и S14 (миграция) больше не являются
требованиями Cliptiq и классифицированы как unsupported с принятым изменением
объёма. Исторические отчёты T11/T14 описывают прежнюю версию, не текущие функции.

Удалены XML-действия из редакторов Windows/macOS/Linux, публичные API и код
кодека/импорта, утилиты SQLite/Realm/NSKeyedArchive, специальная адаптация
вставки импортированных записей, их тесты/фикстуры и CI job Realm migration.
Приложение линкует единственный нативный редактор без XML-варианта.

Обычные форматы системного clipboard и собственная SQLite-БД Cliptiq сохранены.
Существующие пользовательские БД не удаляются и не преобразуются этим изменением.
SQLite storage/schema handling не заменён: он отвечает за сохранность собственных
данных приложения, а не только за перенос из Clipy.

TinyXML2 остаётся как ограниченный парсер Atom-ленты обновлений GitHub.
Он не требует отдельной DLL. Его замена требует отдельного измерения размера и
проверки безопасного разбора сетевых данных. Realm/Swift converter никогда не
входил в основной Base EXE, поэтому его удаление сокращает инструменты/CI,
но не объявляется экономией runtime RAM приложения.

Лицензионные уведомления о производных переводах Clipy сохраняются: отказ от
совместимости не отменяет происхождение использованных переводов.

Ручные release gates других возможностей не закрыты. Gates T11/T14 удалены из
текущего checklist вслед за удалёнными требованиями; production release по-прежнему
заблокирован остальными пунктами.
