# Cliptiq: нативный гибридный интерфейс

Пользователь выбрал гибрид: главное окно и быстрый доступ из трея. Основа —
согласованные в чате история/сниппеты/настройки, предпросмотр, копирование,
удаление, закрытие в трей и сохранение низкого фонового расхода.

## Подходы

Выбран гибрид. Постоянное главное окно удобнее как библиотека, но мешает
фоновой утилите; одна компактная панель недостаточна для управления данными.
Raven/WebView не используются: остаются C++17, Win32, SQLite и текущие сервисы.

## Реализация

Windows первым получает рабочее окно: боковая навигация «История»/«Сниппеты»,
список, фильтр текущего списка, текстовый/готовый image preview и действия.
Фильтр работает по заголовкам/подсказкам, не обещает FTS полного содержимого.
Копирование из окна не отправляет клавиатурный ввод. Удаление доступно для
истории; сниппеты редактируются существующим редактором. Команды проверяют
актуальные stable ID/revision. Просмотр текста читает ограниченный префикс.

«Настройки» открывает текущую форму с улучшенными названиями, списками выбора
вместо числовых кодов и системными шрифтами. Существующий save/validation и
горячие клавиши сохраняются. Окно редактора остаётся отдельным.

Главное окно создаёт тяжёлые контролы по запросу. Закрытие при доступном трее
скрывает owner и уничтожает workspace; выход — явная команда. Если трей недоступен,
видимый launcher остаётся способом восстановления. --background не открывает
workspace. Трей/горячие клавиши сохраняют быстрые native popup menus.

Первый экран показывает понятное пустое состояние. Отображение статуса захвата
опирается на capabilities/настройки, а не обещает работающий capture при отказе.
Все изображения и тексты берутся из существующих локальных данных.

## Границы и проверка

В этом изменении реализуется Windows UI. macOS/Linux сохраняют свои нативные
оболочки; общее ядро/форматы не меняются. Нет новой синхронизации, OCR UI,
снятых XML/migration возможностей или сетевых SDK.

Проверить stale/deleted IDs, copy-only, ограниченный preview, пустую историю,
вкладки и фильтр, клавиатуру, resize/DPI, close-to-tray/reopen/quit. Собрать
Windows, визуально проверить и повторить idle measurements. Известные ограничения
CreateWindowStation/AuthentiCode тестов не скрывать.
