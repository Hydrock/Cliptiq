# Windows idle CPU implementation plan

Goal: reduce measured idle CPU without delaying clipboard input or changing stored user data.
Architecture: advisory Windows event for SQLite launch mailbox; socket readiness and command wake events for LAN workers; no discovery view snapshots when hidden. Keep bounded maintenance/fallback checks, existing authentication, deadlines and database validation. Other OS paths retain existing behavior.

Evidence: temporary QueryThreadCycleTime scopes, isolated 30-second runs: IPC about 45% of controller cycles; LAN worker source wakes each 10 ms; hidden settings still request/serialize discovery snapshots. Main-window 1.95% earlier result is transient and not a stable baseline.
